# PyExZ3 扩展成员函数

## 各类型支持情况总结

### 1. 整数类型 (SymbolicInteger)

#### 已完全支持的功能
```python
# 一元操作类
abs, neg, pos, round, trunc, floor, ceil, conjugate

# 二元操作类  
add, sub, mul, floordiv, truediv, mod, pow
and, or, xor, lshift, rshift

# 比较操作类
eq, ne, lt, le, gt, ge

# 复数属性类
denominator, imag, numerator, real

# 特殊操作类
bool, divmod, format, hash, index, invert

# 右操作版本
radd, rsub, rmul, rfloordiv, rtruediv, rmod, rpow
rand, ror, rxor, rlshift, rrshift, rdivmod

# 实用方法类
as_integer_ratio, bit_length, to_bytes
```

#### 实现特点
- 所有方法返回适当的 SymbolicInteger 或 SymbolicBoolean 类型
- 保持与 Python int 类型的完全兼容
- 支持混合运算（符号值与具体值）

### 2. 字符串类型 (SymbolicStr)

#### 已完全支持的三组方法

**第一组：基础字符串操作**
```python
add, contains, eq, iter, len, mul, ne, rmul
count, find, index, isalpha, isdigit, islower, isupper
lower, replace, upper
```

**第二组：扩展字符串操作**
```python
ge, getitem, gt, le, lt, mod, endswith
isalnum, isnumeric, lstrip, rstrip, split
splitlines, startswith, strip
```

**第三组：高级字符串操作**
```python
format, hash, rmod, capitalize, casefold, center
encode, expandtabs, isascii, isdecimal, isidentifier
isprintable, isspace, istitle, join, ljust, partition
rfind, rindex, rjust, rpartition, rsplit, swapcase
title, translate, zfill
```

#### 实现特点
- 检查方法（如 isalpha, isdigit）返回 SymbolicInteger 类型
- 转换方法（如 upper, lower）返回 SymbolicStr 类型
- 正确处理边界情况（空字符串、特殊字符等）
- 保持与 Python str 类型的语义一致性

### 3. Range类型 (SymbolicRange)

#### 已完全支持的方法
```python
# 核心功能
__init__, __contains__, __iter__, __len__
count, index, __getitem__

# 比较和表示
__bool__, __eq__, __ge__, __gt__, __hash__
__le__, __lt__, __ne__, __reversed__
```

#### 实现特点
- 完整模拟 Python range 对象的行为
- 支持切片操作和迭代
- 正确处理正向和反向 range
- 支持与具体 range 对象的比较
