#### 常量提升（Constant Upcasting）技术  
- **问题描述**：当常量作为调用者时（如`"abc".contains(x)`），x的符号信息会丢失
- **论文解决方案**：通过AST转换将常量提升为符号对象
- **技术原理**：`"abc"` → `SymbolicStr("const", "abc", "abc")`
- **当前状态**：已完整实现AST转换器（`symbolic/ast_upcaster.py`）并集成到加载器
  - 支持常量类型：字符串、整数、浮点数、布尔值
  - 转换模式：`"abc".method(x)` → `SymbolicStr("const", "abc", "abc").method(x)`

#### 内置构造函数符号化 
- **问题描述**：`int(x)`, `str(x)`, `range(x,y,z)`等构造函数会丢弃符号信息

- **论文解决方案**：重写内置构造函数的符号版本

- **技术原理**：`int(x)` → `SymbolicInteger("int", x, ["int", x.expr])`

- **当前状态**： 已完整实现所有主要内置构造函数的符号化
  
  -  **SymbolicInteger.from_symbolic()**：支持int()构造函数
  
  -  **SymbolicStr.from_symbolic()**：支持str()构造函数
  
  -  **SymbolicRange.from_symbolic()**：支持range()构造函数（1-3个参数）
  
  -  **SymbolicFloat.from_symbolic()**：支持float()构造函数
  
  -  **布尔值处理**：bool()使用SymbolicInteger表示
  
  -  **AST转换集成**：通过ast_upcaster.py自动转换
  
    

## 二、向PyCT的改进方向

#### 1：异常处理机制  未实现

- **论文提到**：将异常视为分支条件，通过代码重写插入分支语句
- **示例**：`x = y / z` → `if z == 0: raise ZeroDivisionError else: x = y / z`
- **技术原理**：异常分支加入路径约束队列，探索正常和异常执行路径

#### 2：函数分解技术  未实现
- **论文提到**：对于无法直接表达为TSLIA的函数，通过递归分解为可表达片段
- **示例1**：`s * n` → 递归实现：`if n == 0: "" else: s + (s * (n-1))`
- **示例2**：`str.count(sub)` → `(len(str) - len(str.replace(sub, ""))) / len(sub)`
