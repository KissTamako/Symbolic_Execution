

          
## 现有测试脚本使用说明

---

### 1. batch_wrap_only.py（仅包装，不执行符号执行）

**功能**：只对学生代码进行包装，生成包装后的代码文件，不执行符号执行。

**使用方法**：

```bash
cd E:\Graduation_Projection\PyExZ3-master
python batch_wrap_only.py
```

**配置项**（在脚本开头）：
```python
STUDENT_CODE_DIR = r'e:\Graduation_Projection\PyExZ3-master\student_code'  # 学生代码目录
WRAPPED_DIR = r'e:\Graduation_Projection\PyExZ3-master\student_code_wrapped'  # 包装后保存目录
USE_ENHANCED_WRAPPER = True  # 是否使用增强包装器
```

**输出**：
- 包装后的代码保存在 `student_code_wrapped/` 目录
- 报告保存在 `batch_wrap_report.txt`

---

### 2. batch_test_v2.py（包装 + 符号执行）

**功能**：对学生代码进行包装，然后执行符号执行，并收集测试结果。

**使用方法**：

```bash
cd E:\Graduation_Projection\PyExZ3-master
python batch_test_v2.py
```

**配置项**（在脚本开头）：
```python
# 目录配置
STUDENT_CODE_DIR = r'e:\Graduation_Projection\PyExZ3-master\student_code'
WRAPPED_DIR = r'e:\Graduation_Projection\PyExZ3-master\student_code_wrapped'

# 测试配置
USE_ENHANCED_WRAPPER = True   # 使用增强包装器
MAX_ITER_PER_FILE = 20        # 每个文件最大迭代次数
EXEC_TIMEOUT = 10              # 符号执行超时时间（秒）
WRAP_TIMEOUT = 10              # 包装超时时间（秒）

# 导出配置
ENABLE_SIMPLIFY = True         # 启用表达式简化
DUMP_CONSTRAINTS = True        # 导出约束
DUMP_TRACE = True              # 导出跟踪
DUMP_SEMANTICS = True          # 导出语义信息
DUMP_ALL_EXECUTIONS = True    # 导出所有执行
```

**输出**：
- 包装后的代码保存在 `student_code_wrapped/` 目录
- 测试报告保存在 `batch_test_report_v2.txt`

---

### 3. 运行示例

```bash
# 进入项目目录
cd E:\Graduation_Projection\PyExZ3-master

# 仅包装（快速检查包装是否成功）
python batch_wrap_only.py

# 完整测试（包装 + 符号执行）
python batch_test_v2.py
```

---

### 4. 注意事项

1. **超时设置**：如果符号执行超时，可以修改 `EXEC_TIMEOUT = 10` 为更大的值（如 30）
2. **迭代次数**：如果想探索更多路径，可以修改 `MAX_ITER_PER_FILE = 20`
3. **报告查看**：测试完成后查看 `batch_test_report_v2.txt` 了解详细结果

---
